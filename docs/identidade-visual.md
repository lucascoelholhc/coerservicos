# Identidade visual e front-end: COE Serviços

## Princípios
- **Mobile first** (360 px), responsivo. No celular, menu inferior tipo app.
- Público com pouca familiaridade com tecnologia:
  - poucos campos por tela
  - botões grandes
  - uma ação principal por tela
- Textos em português do Brasil, voz ativa, simples. Ex.: "Aprovar diária", não "Efetuar aprovação".
- O protótipo HTML/CSS/JS navegável é a referência de telas e fluxos.

## Identidade "Enxaimel"
Calorosa e local, **nada minimalista demais**.

| Token | Cor | Uso |
|---|---|---|
| Azul viga | `#1A2E4A` | marca, títulos, estrutura |
| Telha | `#D4602A` | **só para ação** (contratar, aprovar, pagar) |
| Telha escura | `#B84E1F` | texto na cor telha (contraste) |
| Cal | `#F4F5F1` | fundo |
| Verde | `#3E6B4F` | liberado / sucesso |
| Vermelho | `#B42318` | contestado / erro |

- **Fontes:** Zilla Slab (títulos e valores) + Source Sans 3 (texto).
- **Símbolo:** fachada enxaimel com telhado.
- **Elemento gráfico:** faixa de vigas enxaimel.

## Acessibilidade (obrigatório)
- Contraste **WCAG AA**.
- Label visível em todo campo.
- Navegação por teclado, com foco visível.
- Áreas de toque de pelo menos **44 px**.
- Status **nunca** indicado só por cor: sempre texto ou ícone junto.
